# SankeyPlus

通用、可交互、面向发表输出的桑基图编辑器。采用 React、TypeScript、D3 Sankey 和 SVG，当前文档格式为 SankeyPlus v8。

## 运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```bash
npm ci
npm run dev
```

构建与测试：

```bash
npm test
npm run build
```

## 数据格式

CSV、TSV 或粘贴表格需要包含：

```csv
source,target,value,source_group,target_group,link_group
来源 A,处理中,120,入口,处理阶段,路径 A
处理中,去向 1,80,处理阶段,终点,路径 A
```

前三列是必需列；三个分组列均为可选。`value` 必须是大于 0 的数值。当前自动布局面向无环有向流图，循环流会显示明确错误。

## 主要能力

- 跨领域通用示例、密集分类示例与可编辑来源—目标—数值表
- 可选来源分组、目标分组和连接分组，支持 CSV/TSV 往返保存
- 分类色板与有序色板分型；默认 Scientific 12 在常见节点规模内不重复，并提示色板容量与缺失分组
- 节点统一色、按阶段、按分组、逐节点映射，以及可保存的单节点颜色覆盖
- 来源、目标、连接分组、渐变和中性流带着色；同名节点/连接分组共用颜色注册表
- 流带透明度滑块与精确数值输入
- 节点色块纵向拖拽，流带实时跟随并保存位置
- 默认名称标签统一外置且使用固定深色；支持独立拖拽、字体/颜色/粗体/斜体、真实字体宽度测量、智能吸附、Shift 多选、批量对齐与分布
- 自动标签不绘制多余引导线；标签被手动移开后，引导线实时跟随位置
- 首列总量、各列总量或自定义百分比分母；支持单位与小数位
- 无效值、重复流向、循环流和中间节点流量守恒检查
- 标签锁定、重置、方向键微调、撤销与重做
- 画布宽高可手动输入（600–2400 × 400–1800 px）；确认后自动重新布局并按比例保留手动位置
- 本地自动保存
- 自定义毫米成品宽度和 DPI；输出尺寸不会反向修改字体或布局
- 白色/透明背景、毫米尺寸 SVG、带真实 DPI 的 PNG、无损 TIFF、打印/PDF、CSV 和 SankeyPlus JSON 导出
- 导出提醒检查最终字号、标签重叠/越界、文字对比度、数据错误和重复颜色，但不阻止用户导出
- 灰度、红色觉缺陷和绿色觉缺陷校样预览；校样滤镜不会写入导出文件
- 发表清单 JSON：记录工具版本、数据与设置 SHA-256、物理尺寸、百分比口径和预检结果
- 颜色、标签、布局、输出四区单一职责：所有颜色集中在“颜色”，所有字体集中在“标签”，画布几何集中在“布局”
- v1–v7 文档和本地自动保存数据自动迁移到 v8
- 桌面、手机竖屏和手机横屏布局

## 发表级输出流程

1. 在“布局”面板确定画布宽高，点击“应用尺寸并重新布局”。
2. 在“颜色”和“标签”面板完成配色、字体与文字排版；用色觉校样检查可辨识性。
3. 在“输出”面板填写成品宽度（mm）与 DPI。
4. 查看导出提醒并按用途自行判断；提醒不会锁定 SVG、PNG、TIFF 或打印/PDF。
5. 同时导出“发表清单 JSON”，与论文分析记录一起归档。

PNG 和 TIFF 会写入设定的物理 DPI；SVG 会写入毫米尺寸并保留可编辑文字。浏览器无法保证商业字体被嵌入到 PDF/EPS，因此“打印 / PDF”仍需在最终排版软件中检查字体替换。需要 EPS 的期刊建议使用导出的 SVG 在 Inkscape、Illustrator 或期刊指定流程中转换，并再次运行最终尺寸检查。

## 数据与隐私

SankeyPlus 当前是纯浏览器端工具，没有用户账户或后端数据库。导入的数据、编辑状态和自动保存文档保存在当前浏览器本地，不会由应用主动上传到服务器。清除该站点的浏览器存储会同时清除自动保存内容，重要项目请使用“保存项目 JSON”另行归档。

## 构建与部署

```bash
npm run build
```

构建结果写入已忽略的 `dist/` 目录，可部署到静态网站托管服务。若部署在域名子路径下，请先在 Vite 配置中设置对应的 `base` 路径。
